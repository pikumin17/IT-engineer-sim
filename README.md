# IT-engineer-sim

ITエンジニアの仕事を体験しながら、知識も身につけられるスマホ向けブラウザゲーム（学習用の個人開発）。

最初の職種は **クラウドエンジニア**（AWSの構築・運用）。今後、SE・SESなど他の職種も追加予定です。

> 本ゲームは学習用の非公式作品であり、Amazon Web Services, Inc. とは関係ありません。料金は東京リージョンをもとにしたゲーム用の目安です。

## どんなゲーム？

架空の会社「株式会社ソラリンク」に入社した新人クラウドエンジニアとして、現場と同じ流れで仕事をします。

1. **朝会**でチケットを受け取る
2. お客さんに**ヒアリング**（質問は4つまで。何を聞くかで設計が変わる）
3. 構成図を組んで**見積もり**（VPC・サブネット・EC2・ALB・Auto Scaling・RDS・S3・CloudFront・セキュリティグループ・CloudWatch）
4. **作業手順書**を書いて先輩のレビュー（作る順番と切り戻し）
5. CloudShell風のターミナルで**動作確認**して本番公開
6. **障害対応**：アラーム→グラフとコマンドで調査→原因→止血→再発防止→障害報告書

### 続けたくなる仕組み
- **作った環境があとで返ってくる**：公開したシステムは残り続け、弱点があるほど障害が起きやすい。ちゃんと作った構成は「構成のおかげで無事」と知らせが来る
- 研修（1週間）のあとは**ランダムな案件**が続く
- **出世と社内資格**（AWS認定の範囲を参考にしたクイズ）。ランクが上がると大きな案件
- **今日の障害対応**（日替わり・連続日数）
- **用語図鑑**・実績・**苦手な言葉の復習**

## 技術

| 使うもの | 用途 |
|---|---|
| React + TypeScript + Vite | 画面とゲームの中身 |
| Vitest | ゲームの中身のテスト（研修を模範解答で通す、60日自動プレイ、セーブの保存→読み込みなど） |
| localStorage + JSON書き出し | セーブ（サーバーなし） |
| PWA（manifest + Service Worker） | iPhoneのホーム画面に追加して使う |
| GitHub Actions | 型チェック・テスト・ビルドを自動実行 |
| Vercel | 公開 |

計算部分（`src/engine`）と画面（`src/ui`）を分けてあり、判定ロジックは画面なしでテストできます。

設計書（ユースケース図・クラス図・シーケンス図・状態遷移図・DFD）：[docs/design.md](docs/design.md)

## 動かし方

```bash
npm install
npm run dev     # 開発用サーバー
npm test        # テスト
npm run build   # 本番用ビルド（dist/）
```
